## Live schema references

Your running server remains the source of truth for generated schemas:

| Protocol | Reference |
| --- | --- |
| REST | `http://127.0.0.1:3000/api/v1/docs` |
| GraphQL | `http://127.0.0.1:3000/api/graphql` |
| gRPC | `cms.proto` distributed with the project/source release |
| MCP | `tools/list` and `resources/list` after initialization |

Collection definitions can vary by site, so inspect the active site schema before generating consumer types.
