---
title: Use the REST API
description: Read and change site resources through `/api/v1`.
---

REST serves site-scoped resources under `/api/v1`. A site key supplies the site context.

## Read a singleton

```bash
curl http://127.0.0.1:3000/api/v1/singletons/site-settings \
  -H "Authorization: Bearer $VCMS_TOKEN"
```

## Get one entry

```bash
curl http://127.0.0.1:3000/api/v1/entries/ENTRY_ID \
  -H "Authorization: Bearer $VCMS_TOKEN"
```

## Create an entry

Use a write key and the collection ID returned by the collections endpoint.

```bash
curl -X POST http://127.0.0.1:3000/api/v1/entries \
  -H "Authorization: Bearer $VCMS_WRITE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "COLLECTION_ID",
    "slug": "api-created-post",
    "data": {"title": "Created through REST"}
  }'
```

## Publish an entry

```bash
curl -X POST http://127.0.0.1:3000/api/v1/entries/ENTRY_ID/publish \
  -H "Authorization: Bearer $VCMS_WRITE_TOKEN"
```

Open `/api/v1/docs` on your server for current request bodies and response schemas.
