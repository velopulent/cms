| Protocol | Endpoint | Best fit | Canonical schema |
| --- | --- | --- | --- |
| REST | `/api/v1/*` | Web builds, scripts, broad HTTP tooling | `/api/v1/docs` |
| GraphQL | `/api/graphql` | Clients choosing response fields | GraphiQL introspection |
| gRPC | port `50051` | Typed service-to-service clients | `cms.proto` |
| MCP | `/mcp` | AI agents and tool clients | `tools/list`, `resources/list` |

All four protocols use the same stored content and authorization policy. Protocol coverage differs: inspect the operation catalog and live schema before choosing one for a write workflow.

## Selection guidance

Choose REST for small integrations and static builds. Choose GraphQL when a consumer benefits from GraphQL tooling or selective response shapes. Choose gRPC when generated clients and binary transport fit the service environment. Choose MCP when an agent should discover tools and site schemas at runtime.

One application can use more than one protocol. Give each consumer its own minimal credential.
