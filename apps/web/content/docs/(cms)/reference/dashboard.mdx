The dashboard lives at `/dashboard`. Authentication routes live under `/api/auth`; dashboard resource requests use `/api/dashboard/v1`.

## Troubleshooting navigation

If a menu item is absent, compare your role with the [permission reference](./permissions). If the whole site is absent, ask an operator to verify membership. Operators should verify that the requested site still exists and that the user is not already an instance operator before inviting them.
