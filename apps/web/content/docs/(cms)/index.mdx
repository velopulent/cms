## Product map

| Area | Purpose |
| --- | --- |
| Sites | Isolate schemas, content, files, integrations, and collaborators |
| Collections | Define repeatable records such as posts and authors |
| Singletons | Define one record such as site settings or a home page |
| Files | Upload, browse, reference, trash, restore, and serve media |
| Deploy | Notify a frontend build service when content changes |
| Settings | Manage site identity, members, keys, MCP, webhooks, and backups |

Instance operators also receive installation-wide settings for users, security, storage, and backups.

<Callout type="info">
Menu items depend on your role. A viewer sees readable site resources. An editor can change content and files. Instance operators manage schemas and site settings.
</Callout>
