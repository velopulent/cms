---
title: Secure your account
description: Change profile details, password, sessions, and personal access tokens.
---

## Update profile and password

Open the account menu and select **Account**. Your email identifies the login; display names do not need to be unique. Change the temporary first-run password immediately.

## Review sessions

The sessions list shows active sign-ins. Revoke all other sessions after a lost device, unexpected access, or password exposure.

## Create a personal token

Personal tokens act with the user's identity and assigned scopes. Give each integration a descriptive name, minimal scopes, and an expiry date when possible.

Copy the raw token when created. The dashboard stores and displays only its prefix afterward.

## Revoke a token

Revoke the token from the account page, then replace it in the integration. Token revocation does not sign out dashboard sessions.
