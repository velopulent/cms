---
title: Manage files
description: Upload, reference, serve, trash, restore, and permanently delete site media.
---

Files belong to one site and use that site's selected storage profile.

## Upload files

Open **Files**, choose **Upload**, select the files, and wait for each upload to complete. Fresh instances accept files up to 50 MB unless an owner changes the upload limit.

Images can receive thumbnails. Other media remains available through its original file endpoint.

## Use a file in content

Open an entry and use its file field. The picker filters by the field's accepted media category. Select the file and save the entry.

## Check references

Before deletion, open the file's references. Replace or remove references from entries that still need valid media.

## Trash and restore

Delete moves a file to trash. Open the trash view and choose **Restore** to return it. Batch actions can trash or restore several selected files.

## Permanently delete

Permanent deletion removes selected trashed files from storage and cannot be undone through the dashboard. Confirm references and create a backup first.

<Callout type="warn">
Deleting a file record does not rewrite content that points to it. Resolve references before permanent deletion.
</Callout>
