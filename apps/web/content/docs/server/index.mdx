## Runtime surfaces

| Surface | Default |
| --- | --- |
| Dashboard and HTTP APIs | `127.0.0.1:3000` |
| gRPC | `127.0.0.1:50051` |
| Liveness | `/health/live` |
| Readiness | `/health/ready` |
| Portable data | `<current directory>/vcms_data` |

Native service registration selects installed mode. Directory existence and old paths never select a runtime mode.
